Delivery Note 私隱政策

生效日期：2026 年 11 月 18 日（同日更新：只要求一項 Google 權限）

1. 適用範圍

本政策適用於「Delivery Note」（送貨單記錄系統），一個只供本公司內部同事使用的 Windows 桌面程式。

2. 本程式存取的 Google 資料

  • 由本程式建立的 Google 雲端硬碟檔案及試算表（drive.file，本程式唯一要求的權限）：用於建立資料夾、上載送貨單圖片，以及在試算表新增記錄。本程式看不到使用者雲端硬碟內的其他檔案。
  • 帳戶電郵地址：透過上述權限讀取雲端硬碟帳戶資料中的電郵地址，只用於在程式內顯示目前登入的帳戶。

3. 資料的用途

上述資料只用於把送貨單資料記錄到使用者自己的 Google 試算表及雲端硬碟，不作其他用途，不用於廣告，亦不會用作訓練任何人工智能模型。

4. 資料存放及分享

  • 送貨單資料及圖片只存放在使用者自己的 Google 帳戶，以及使用者自己的電腦。
  • Google 授權資料以作業系統的加密功能保存在使用者的電腦，不會傳送到任何其他伺服器。
  • 本程式沒有自己的伺服器，不收集、不出售，亦不與任何第三方分享資料。

5. 取消授權及刪除資料

使用者可以隨時在程式「設定 › Google」按「登出」，或者到 Google 帳戶 › 第三方應用程式 取消本程式的存取權。雲端硬碟內由本程式建立的檔案，使用者可以自行刪除。

6. Google API 服務使用者資料政策

本程式使用從 Google API 取得的資料時，會遵守 Google API 服務使用者資料政策， 包括其中的「有限使用」規定。

Privacy Policy (English)

Effective date: 18 November 2026

This policy applies to "Delivery Note", an internal Windows desktop tool used only by our own staff.

Data accessed. The app requests only the drive.file scope, which it uses to create its own folder, upload delivery-note images and add rows to the spreadsheet it creates. It cannot see any other files in the user's Google Drive. Through the same scope it reads the signed-in account's email address from Google Drive, only to show which account is signed in.

Use. The data is used only to record delivery notes in the user's own Google Sheet and Google Drive. It is not used for advertising and is not used to train any AI model.

Storage and sharing. Data stays in the user's own Google account and on the user's own computer. Authorization tokens are stored encrypted on the user's computer by the operating system. The app has no server of its own and does not collect, sell or share any data with third parties.

Revoking access. Users can sign out in the app (Settings › Google) or remove the app at Google Account › Third-party apps at any time, and may delete the files the app created.

Google API Services User Data Policy. The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
