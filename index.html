Delivery Note

Delivery Note（送貨單記錄系統）是一個供本公司內部使用的 Windows 桌面程式。 它在使用者自己的電腦上識別掃描後的送貨單，然後把送貨單的日期、店舖編號及發票編號 記錄到使用者自己 Google 帳戶內的 Google 試算表，並把送貨單圖片存放在同一帳戶的 Google 雲端硬碟。

本程式不對外提供服務，亦不會出售或分享任何資料。

使用 Google 帳戶的原因

本程式只要求 Google 的「drive.file」權限，即只能存取由本程式自己建立的檔案及試算表， 看不到使用者雲端硬碟內的其他檔案。詳情請參閱 私隱政策。

Delivery Note (English)

Delivery Note is an internal Windows desktop tool used only by our own staff. It recognises scanned delivery notes on the user's computer and records the date, shop code and invoice number into a Google Sheet in the user's own Google account, and stores the delivery-note images in the same account's Google Drive.

The app only requests the drive.file scope, so it can access only the files and spreadsheet that it creates itself. See the Privacy Policy.
